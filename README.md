# 🚣 Система бронирования сплавов

Комплексная система на Google Apps Script с Telegram-интеграцией.

## 📋 Быстрый старт

### 1. Создание Google Таблицы
1. Откройте [Google Sheets](https://sheets.google.com)
2. Создайте новую таблицу
3. Перейдите в **Расширения → Apps Script**

### 2. Установка кода
1. Удалите весь код в `Code.gs`
2. Скопируйте содержимое файла `Code.gs` из этого проекта
3. Создайте новый HTML-файл: **Файл → Создать → HTML-файл**
4. Назовите его `Index`
5. Скопируйте содержимое файла `Index.html`

### 3. Настройка Telegram бота
1. Откройте [@BotFather](https://t.me/BotFather) в Telegram
2. Отправьте `/newbot` и следуйте инструкциям
3. Скопируйте токен бота
4. Узнайте свой Chat ID через [@userinfobot](https://t.me/userinfobot)

### 4. Конфигурация
В файле `Code.gs` найдите блок `CONFIG` и заполните:

```javascript
const CONFIG = {
  BOT_TOKEN: 'YOUR_BOT_TOKEN_HERE',           // Токен от BotFather
  ADMIN_CHAT_ID: 'YOUR_ADMIN_CHAT_ID_HERE',   // Ваш Chat ID
  PAYMENT_LINK_AUTO: 'https://...',            // Ссылка на оплату 20 BYN
  // Остальное не трогать
};
```

### 5. Инициализация таблицы
1. В Apps Script выберите функцию `initializeSpreadsheet`
2. Нажмите **Выполнить**
3. Разрешите доступ при первом запуске
4. Проверьте, что создались листы: Сплавы, Отчеты, Статистика, Users, Логи

### 6. Заполнение данных о сплавах
Откройте лист **Сплавы** и добавьте строки:

| Дата | Маршрут | Тип | Лимит людей | Лимит 2-мест | Лимит 3-мест | Лимит трансфера | Активен | Программа | Памятка | GPS | Цена взр | Цена дет | Цена трансфер |
|------|---------|-----|-------------|--------------|--------------|-----------------|---------|-----------|---------|-----|----------|----------|---------------|
| 01.05.2026 | Вилия | 1 день | 30 | 10 | 5 | 30 | Да | Описание программы | Что взять с собой | 54.123,27.456 | 50 | 30 | 15 |

### 7. Развертывание веб-приложения
1. В Apps Script нажмите **Развернуть → Новое развертывание**
2. Тип: **Веб-приложение**
3. Описание: `Booking System v1`
4. Выполнять от имени: **Меня**
5. У кого есть доступ: **Все**
6. Нажмите **Развернуть**
7. Скопируйте URL веб-приложения

### 8. Настройка Telegram Webhook
1. В Apps Script выберите функцию `setupWebhook`
2. Нажмите **Выполнить**
3. Проверьте логи: должно быть `Webhook установлен: {"ok":true,...}`

## ✅ Проверка работы

1. Откройте URL веб-приложения
2. Заполните форму
3. Отправьте бронирование
4. Проверьте:

   - Данные попали в **Отчеты**

## 🐛 Решение проблем

### Webhook не работает
```javascript
// Проверьте URL в настройках бота
function checkWebhook() {
  const url = `https://api.telegram.org/bot${CONFIG.BOT_TOKEN}/getWebhookInfo`;
  const response = UrlFetchApp.fetch(url);
  Logger.log(response.getContentText());
}
```

### Форма не загружается
- Проверьте права доступа в развертывании
- Убедитесь, что выбрано "Все" в доступе
- Очистите кеш браузера

### Даты не подгружаются
- Запустите `initializeSpreadsheet`
- Заполните лист **Сплавы**
- Проверьте столбец **Активен** (должно быть "Да")
