ИНСТРУКЦИЯ ПО НАСТРОЙКЕ GOOGLE SHEETS

1. Откройте Google Sheets и создайте новую таблицу

2. Перейдите в Расширения → Apps Script

3. Удалите весь код в файле Code.gs и вставьте содержимое из файла Code.gs

4. Создайте новый файл: Файл → Создать → HTML файл
   Назовите его "Index"
   Вставьте содержимое из файла Index.txt

5. Создайте новый файл: Файл → Создать → Файл скрипта
   Назовите его "Advanced"
   Вставьте содержимое из файла Advanced.gs

6. В файле Code.gs замените:
   - BOT_TOKEN: 'YOUR_BOT_TOKEN_HERE' → ваш токен Telegram бота
   - ADMIN_CHAT_ID: 'YOUR_ADMIN_CHAT_ID_HERE' → ваш chat_id в Telegram

7. В файле Index.txt (строка ~755) замените:
   - const botUsername = 'YOUR_BOT_USERNAME'; → имя вашего бота (без @)

8. Сохраните проект (Ctrl+S или Cmd+S)

9. Запустите функцию initializeSpreadsheet():
   - Выберите функцию "initializeSpreadsheet" в выпадающем списке
   - Нажмите "Выполнить"
   - Разрешите доступ к таблице

10. Заполните лист "Сплавы" данными:
   Пример строки:
   Дата: 2026-05-01
   Время: 10:00
   Маршрут: Река Припять
   Тип: Однодневный
   Лимит людей: 20
   Лимит 2-мест: 10
   Лимит 3-мест: 5
   Лимит трансфера: 20
   Активен: Да
   Программа: Сплав 15км
   Памятка: Взять с собой...
   GPS: 52.1234, 26.5678
   Цена взр: 50
   Цена дет: 30
   Цена трансфер: 15
   Дни: Выходной (или "Будний")

   ВАЖНО про колонку "Дни":
   - "вых" (или "Выходной") — сплав состоится при любом количестве людей
   - "буд" (или "Будний") — показывается предупреждение про минимум 12 человек
   - Можно писать с любой буквы: "вых", "ВЫХ", "Вых" — все варианты работают
   - Программа НЕ определяет праздники автоматически, вы указываете тип дня вручную
   - Если праздник выпадает на будний день календаря, укажите "вых"

11. Разверните веб-приложение:
    - Нажмите "Развернуть" → "Новое развертывание"
    - Тип: Веб-приложение
    - Выполнять от имени: Меня
    - У кого есть доступ: Все
    - Нажмите "Развернуть"
    - Скопируйте URL веб-приложения

12. Настройте Telegram Webhook:
    - Запустите функцию setupWebhook() в Apps Script
    - Это свяжет бота с вашим веб-приложением

13. Готово! Теперь можно открыть форму по URL
